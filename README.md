# ZMRT Web Version

Responsive Arabic RTL marketing website. Static HTML/CSS/JavaScript, no build or paid dependencies. Contains home, privacy, terms, delete-account, support and 404 pages. UI artwork is illustrative, not an app screenshot. No unverified extra product features or security claims are included.

## Open
Extract ZIP then open index.html. Links use relative file paths so they work locally. For clean URL paths /privacy and /terms, deploy the folders with an index.html-aware static host. Nothing in this ZIP has been published as a website.

## Configure
Edit config.js: GOOGLE_PLAY_URL (real Android app listing URL), SUPPORT_EMAIL (verified support inbox), DEVELOPER_NAME, SITE_URL and LEGAL_APPROVED. Support uses mailto; it does not implement account deletion. Current legal pages are deliberately marked drafts. Replace with verified app-specific policies, validate real deletion workflow, remove noindex meta and enable robots only after approval. No sitemap contains an invented domain; create one from the confirmed production domain.

## Quality
Source syntax and archive integrity checked; visual/browser tests could not run because the execution environment was unavailable. Manual check mobile menu, layout at 360px/768px/1440px, keyboard navigation and reduced motion. Source is framework-free for immediate opening and deployment; React/Tailwind/Framer Motion are not dependencies of this delivery.
